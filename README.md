# Portafolio — Gherson Torres

Portafolio web personal de **Gherson Steven Torres**, Ingeniero de Software especializado en TI, Microsoft 365, automatización, datos e inteligencia artificial.

## Documentación

Análisis detallado del proyecto (qué es, tecnologías, arquitectura, secciones, datos y observaciones):

## Stack

- React 19
- Vite 8
- CSS nativo (variables, nesting, dark mode)
- Formspree (formulario de contacto)
- Google Fonts (Inter + Merriweather)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Estructura principal

- `src/App.jsx` — composición de secciones
- `src/componentes/layout/` — Header, Hero, Clientes, Trabajos, AcercaDe, Contacto, Footer
- `src/componentes/data/trabajos.jsx` — catálogo de proyectos
- `public/assets/` — imágenes, logos y video del hero
